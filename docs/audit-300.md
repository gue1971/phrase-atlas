## 重複・近接項目

機械的な重複チェックでは、完全な重複IDや同一カードの重複は見つかっていません。

近接しているが、独立項目として残す価値があるもの:

- `チューリング・テスト` / `チューリング完全` / `P対NP問題`
- `因果応報` / `輪廻` / `解脱` / `他力本願` / `南無阿弥陀仏`
- `わび・さび` / `幽玄` / `もののあはれ` / `花鳥風月` / `雪月花`
- `囚人のジレンマ` / `ゼロサムゲーム` / `ナッシュ均衡`
- `外部性` / `コースの定理` / `共有地の悲劇`

これらは検索で近くに出る方が学習価値が高いため、削除せず、将来的には関連語リンクでつなぐのがよいです。

## 次の方針

第2目標を400件にする場合、次の追加順が堅いです。

1. 数学・情報 +20
2. 文学・芸術 +20
3. 日本思想 +20
4. 神話・故事 +20
5. 近現代社会・政治経済 +20

UI面では、300件以降は以下の改善が効きます。

- 詳細モーダルに関連語を表示
- 人物別・時代順の導線を追加
- 目次でカテゴリごとに折りたたみ
- 「未読だけを一枚引く」ランダム学習

まずは関連語リンクが最も効果的です。データを増やした価値を、次のカードへ進む導線に変えられます。
